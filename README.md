# ShekaraBenchmark

Тілдік модельдердің қазақ тілін білу деңгейін бағалауға арналған кешенді бенчмарк

1. Бағалау категориялары

Тілдік түсіну (Linguistic Understanding)
Логикалық ойлау (Logical Reasoning)
Математикалық қабілеттер (Mathematical Abilities)
Мәдени білім (Cultural Knowledge)
Контекстік түсіну (Contextual Understanding)

2. Тестілеу форматы

Көп таңдаулы сұрақтар (MCQ)
Еркін жауап сұрақтары (FRQ)
Толықтыру тапсырмалары (CT)
Пайымдау тапсырмалары (RT)
